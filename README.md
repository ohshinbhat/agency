# First Run

An Astro agency website in the Track Meet brand direction.

```sh
npm ci
npm run dev
npm run build
```

The homepage and contact page are under `src/pages`. Update the client names and optional logos, concept projects, and services in `src/content.ts`.

The contact form validates entries in preview mode. To receive inquiries, deploy to Netlify using the included `netlify.toml`, enable form detection, redeploy, and configure the email notification recipient in the project dashboard.
